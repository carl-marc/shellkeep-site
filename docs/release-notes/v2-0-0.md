**Released:** 19 July 2026

## v2.0.0 (116)

### Features

- Added Fusion Generate, use 3 cards & gems to control the minimum rarity of a generated card
- Added Merge screen, see all the possible merges & which ones create cards you need for your collection
- Added sounds
- Redesigned home screen, see your stats and last 7 cards

### Balancing

- The same card will no longer be listed multiple times in the marketplace
- Marketplace shows more rare cards
- Can only buy a Daily Deal once

### Improvements

- Card generation: added different animations for shield reveal based on rarity
- Card generation: glowing colours no longer leak the egg rarity
- Only show cards that can be merged when you have 4/26, so merging doesn't mean you have to find that card again
