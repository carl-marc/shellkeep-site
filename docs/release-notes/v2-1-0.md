**Released:** 22 July 2026

## v2.1.0 (119)

### Features

- Added a Sell button on the collection screen to make finding duplicate cards to sell easier

### Balancing

- Moved Daily Tasks milestone rewards to 4, 7 and 10
- Daily Tasks auction wins are now added automatically, rather than when you claim the card from your inbox

### Improvements

- The screen no longer turns off while exporting videos
- Tapping a club feed item now shows the card larger, with a button to view the player's profile
- Collecting an auction win now looks more like the create-card screen
- Better UI for building Daily Deals more than once

### Bug fixes

- Fusion button hiding when you don't have enough gems to play it
