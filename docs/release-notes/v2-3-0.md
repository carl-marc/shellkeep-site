**Released:** 16 August 2026

## v2.3.0 (128)

### Features

- Four new achievements to chase:
  - Cards Fused
  - Shiny Merges
  - Different Cards Collected
  - Different Shinies Collected

### Improvements

- Added a celebration screen when you complete a full collection
- Clubs: added weekly stats for normal and shiny merges, fusions and daily tasks completed
- Clubs: added all-time stats for cards created and sold, auctions won, normal and shiny merges, and fusions
